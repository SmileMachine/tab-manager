- 已实现 `prepare:local` / `dev` / `restore:local` 及 Chrome 对应命令；开发与独立构建隔离，固定安装目录发布，退出冻结 watcher 后恢复，host 确认新后台再报告成功。

- 完整 Vitest：63 文件 / 305 测试通过；类型检查、Edge/Chrome 正式构建与产物隔离检查通过。
- Node 进程测试覆盖真实 host 无 MCP 连接、认证/目标/非法请求/重复请求、重载新启动确认、发布失败回滚、并发互斥和退出幂等。
- `npm run verify:runtime` 已验证真实 WXT 的 Vite 模块转换与 HMR WebSocket、真实 host 请求接受和新启动确认、重复退出信号、显式恢复及 host 缺失时不修改安装；扩展端为模拟，不是浏览器验收。

- 未完成：真实 Edge/Chrome 连续自动切换与页面 HMR、无 host 的干净发行环境功能验收、用户安装 ID/偏好及业务开关的浏览器验收；完整构建失败恢复与配置重启的异常组合还需增加集成覆盖。

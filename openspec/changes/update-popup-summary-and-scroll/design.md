# Popup 摘要与滚动修正设计

## 摘要结构

每个统计卡片采用两行：

```text
42 / 512
 tabs · current / all
```

第一行使用当前窗口数量 / 全部窗口数量。第二行只保留必要的解释，避免新增大段说明文字。

## 版本号

从 `chrome.runtime.getManifest().version` 读取当前安装版本，在 `Tab Group` 右侧以低对比度的小字号显示。开发环境没有扩展 runtime 时不显示版本号，不影响组件测试。

## 滚动模型

- `html`、`body` 和 popup 根容器不允许文档级滚动。
- popup 根容器使用固定的最大高度，并以 flex 布局分配空间。
- 仅 `.popup-scroll-area` 承担纵向滚动。
- 头部、摘要和搜索框保持在滚动区域外，用户滚动列表时仍能看到核心入口。

## 不在本次范围

- 不改变 popup 的宽度和现有导航功能。
- 不增加独立的窗口切换控件。
